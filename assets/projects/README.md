# Hackathon project assets and sources

- `dreammotion-hackathon.webp`: photo supplied by the site owner on October 11, 2026, converted to WebP at its original 1280 × 853 dimensions. The full composition is preserved.
- `munich-ai-hackathon.webp`: robot throwing demonstration supplied by the site owner on October 11, 2026, converted to WebP at its original 2476 × 920 dimensions. The full RGB and depth views are displayed in the LeThrower project card without cropping.
- [DreamMotion repository](https://github.com/maedmatt/DreamMotion): identifies the project as built at HACK26, organized by ETH Robotics Club. The site's short description of real-time conversation and physical interaction is supplied by the site owner.
- [LeThrower repository](https://github.com/Chiniklas/LeThrower): identifies the project as built at LeRobot Hackathon Munich 2025, and describes reinforcement learning and flow matching for robotic throwing. The site summarizes these methods in one sentence.
